About this site

This site collects academic talks and seminars from social science units at Hong Kong universities into a single searchable list.

How it's built

A GitHub Actions workflow runs automatically once a day (00:00 UTC), plus on demand. It fetches the latest event listing from each university below, pulling date, time, venue, and (where the source publishes it) speaker for every talk — for some universities that means visiting each individual event page. Talks are dropped once their date is more than 3 days in the past, and each talk's discipline is classified by matching keywords in its title. The results are written to talks.json, which this page fetches directly in the browser — there's no server or database involved, and no manual updating.

Notes

Discipline tags are generated by keyword matching, not by the universities themselves, and can be imprecise. A talk is listed only if a clear date could be extracted from its listing; talks without a parseable date are left out rather than shown with missing information. Speaker names are shown where the source publishes them in the listing — some universities don't. Each talk links back to its original page for full, authoritative details.
